# Bluestock Week 2 Data Analytics Assignments

This repository contains my Week 2 assignments completed during the Bluestock FinTech Data Analytics Internship.

## Assignments Included

1. **Stock Market Fundamentals and Infosys Analysis**
   Covers stock market concepts, financial terms, and Infosys financial performance.

2. **Infosys Financial Analysis**
   Contains financial data, observations, and a comparison chart using Excel.

3. **API Data Extraction**
   Demonstrates extracting JSON data from a public REST API using Python.

4. **API Data CSV File**
   Contains the JSONPlaceholder user data converted into CSV format.

5. **Software Architecture Diagram**
   Shows the flow from the user interface to the backend, database, ETL pipeline, and analytics dashboard.

6. **FinTech Research Report – Zerodha**
   Explains Zerodha’s services, trading lifecycle, and the use of data analytics in FinTech.
